    How it works

    Two passes on one GPU. Counting in code, wording by the model.

    01 · read

    Every review, one JSON

    Gemma 3 12B returns fit direction, other causes from a fixed list, the exact quote, and a one-line fix. Batched generation in bf16 on ROCm PyTorch.

    02 · count

    Shares come from code

    The product's "runs small" share and cause mix are plain counts over the per-review answers, so the model cannot inflate a problem.

    03 · write

    The fix a seller pastes

    A second Gemma pass sees only those counts and real quotes, and writes the size note, the description line, and the photo to add.
